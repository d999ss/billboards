# Utah Billboards — Own the Land + the Sign

Personal investment venture + scalable SEO landing-page network. Compiled 2026-05-18.

## What this is

Two linked plays off one asset class (outdoor advertising / OOH):

1. **The asset play** — acquire owned-land + owned-billboard sites, run for ~9% unlevered cash flow, create value via (a) digital conversion where permitted and (b) assembly past $1M aggregate NOI to trigger a multiple re-rate, then sell the book to Reagan / Lamar / OUTFRONT.
2. **The network play** — a 50-state programmatic SEO landing-page network (`<state>-billboards.com`) that serves a **dual audience off the same geo traffic**: advertisers (route to pricing flagship) and investors (route to the thesis memo). The asset doc is the content prototype for each state node.
